# The canon, as working rules

A paraphrase of the rules in The Vignelli Canon (Massimo Vignelli, Lars Müller, 2010), arranged for use by an agent. The book is free to read from RIT's Vignelli Center. Do not quote it at length; apply it.

## The tangibles

| Topic | The rule in print | On screen | In other media |
|---|---|---|---|
| Paper sizes | Prefer the A series; standard sizes save money and give good proportions. | Fixed max width (1440px); fixed-ratio panels. | Posters A2/A1 or 50×70, 70×100 cm; packaging panels sized from a module. |
| Grid | Choose a grid of columns (2–4 for books, 6+ for newspapers) and modules (2–8 rows). Leading lines up with the modules. | 12 columns; 24px line module; row heights in multiples of 24px. | Poster grids such as 4×8, 6×6, 3×6. Packaging panels on one module. |
| Margins | Narrow outer margins create tension; wide margins create calm. Choose deliberately. | 24px outer margin (tension) by default. | State the choice in the brief. |
| Gutters | Tight: about one line of type. | 24px. | Equal to body leading. |
| Typefaces | A handful of classic faces is enough: Garamond, Bodoni, Century Expanded, Helvetica as the core; Futura, Times, Univers, Optima, Caslon, Baskerville beside them. | Two families per project at most. | Same. One family is better. |
| Type sizes | Usually no more than two sizes on a page; display at about twice the text size. A subhead can be text size in bold. | No more than three sizes per screen (label, body, one display). | Posters: two sizes. Packaging: two plus legally required small text. |
| Alignment | Flush left by default. Centred only for invitations, cards and the like. Justified is contrived. | Flush left, everything. | Flush left; centred never. |
| Rules | Heavy (about 2pt) between major parts, light (½–1pt) within parts. Type hangs from the rule above. | 2px and 1px only. | 2pt and ½pt. |
| Contrast | Large against small creates hierarchy and energy. | One very large element per screen. | One dominant element per poster or panel. |
| Scale | Fit the context; break scale on purpose for effect. Control every detail. | The figure size (128px) used once. | Type as image on posters. |
| Texture | Light, finish and paper carry meaning. | No texture effects. Flat colour only. | Name the stock and finish in the spec. |
| Colour | Primaries preferred. Colour signifies and identifies; it is not pictorial. | Black, white, one red; blue and yellow as category identifiers. | Same; spot colours named. |
| Layout | Forceful, never limp. A good layout almost disappears. Avoid repetitive sequences. | Bands of content on one grid; same structure on every screen. | Same. |
| Sequence | A publication is cinematic: plan the order of spreads. | Flows across screens are sequences; vary pace. | Multi-panel packaging and folded posters are sequences. |
| Identity and diversity | Constants carry identity; variables keep attention. Too much of either fails. | Band, grid and type constant; content varies. | Series designs: fixed frame, changing image. |
| White space | More important than the black. Like space in architecture. | Empty columns on purpose. | Leave at least a third of a poster empty. |

## The intangibles, as review questions

Ask these before delivering anything.

1. **Semantics.** Do I understand the subject? Does every element have a reason?
2. **Syntactics.** Are grid, type, sizes and images in consistent relationships?
3. **Pragmatics.** Would someone understand it without explanation?
4. **Discipline.** Is every detail on the grid, in the scale, in the palette?
5. **Appropriateness.** Is the medium, scale and tone right for this subject?
6. **Ambiguity.** Is any double meaning controlled, or is it confusion?
7. **Design is one.** Would this hold up next to the Vignellis' print work?
8. **Visual power.** Is there one clear idea, expressed with force?
9. **Intellectual elegance.** Is anything vulgar, trendy or clever for its own sake?
10. **Timelessness.** Will it look right in 20 years?
11. **Responsibility.** Does it serve the user and the client, not my ego?
12. **Equity.** If an identity exists, have I refreshed it rather than replaced it?

## The slop test

Output fails if any of these are true. Fix before delivering.

- It could belong to any product: swap the name and nothing else changes.
- It uses a template shape: centred hero with eyebrow chip, three feature cards with icons, gradient background, testimonial carousel.
- It uses rounded cards, shadows, glass, gradients, pastel or beige backgrounds, purple accents.
- It uses Inter, Space Grotesk or a "modern" face for no reason.
- Colour is used without a meaning.
- Icons are decoration, not information.
- Every block has the same weight; nothing dominates.
- White space is uniform padding rather than intended emptiness.
- More than three type sizes appear in one view.
- Elements sit off the grid or off the 24px module.

## The intentional test

Output passes only if all of these are true.

- You can name the grid (columns × modules) and every element sits on it.
- You can name each typeface and size used and why.
- You can say what each colour means.
- There is one dominant element.
- There is deliberate empty space.
- It would survive being printed in black only.
